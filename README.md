# ADAPT Template Repository
**Densight Labs — Applied AI. Not just talked about.**

This is the standard template for creating new repositories under the ADAPT Framework. It ensures consistency across all Densight Labs projects while maintaining our practitioner-first, zero-fluff approach.

## What Is Inside
- Pre-configured README structure with ADAPT phase integration
- Standard LICENSE (MIT) and CONTRIBUTING guidelines
- GitHub Actions workflow templates for CI/CD
- Issue and PR templates aligned with ADAPT methodology

## ADAPT Phase: Foundation
This template establishes the baseline structure for all ADAPT repositories, ensuring every project starts with clear documentation and consistent workflows from day one.

## Template
**Use this when:** Starting any new ADAPT Framework repository or documentation project.
**Key Fields:**
- Repository name (lowercase-hyphenated)
- One-sentence description under 100 characters
- ADAPT phase assignment (Assess/Design/Architect/Pilot/Transform)
- Target topics (5 relevant tags)
- Primary use case or problem solved
- Example implementation snippet

**Example:**
Repo: `customer-churn-predictor`
Description: "ML pipeline predicting B2B SaaS churn using ADAPT Framework — Densight Labs"
Phase: Pilot
